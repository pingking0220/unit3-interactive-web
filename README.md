# 第 3 單元：我們只有一個地球互動知識全景圖

這是一份可離線瀏覽、也可部署到 GitHub Pages 的互動式自然科學學習網頁。

## 內容特色

- 5 張 16:9 知識全景圖
- 熱點互動閱讀與延伸補充
- 每頁 15 題題庫，每次隨機呈現 5 題
- 必須 5 題全對才算精熟通過
- 適合教師課堂導覽、學生自主學習與複習

## 使用方式

直接開啟 `index.html` 即可使用。

若部署到 GitHub Pages，可分享網址給學生或其他老師，無須額外安裝。

## 教學主題

- 臺灣的生物多樣性
- 外來入侵種與生態平衡
- 人類活動對環境的影響
- 全球環境變遷與全球暖化
- 打造永續家園行動圖
